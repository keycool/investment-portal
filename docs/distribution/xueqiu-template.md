## 语气与长度规范（2026-11-26 定版：卡兹克观察短文风）

- **脚本先出骨架、再润色口吻**：先运行 `distribute.py` 派生 3 短段事实骨架与 `$代码$` 关联，再参照策展台 [kazike-style-card.md](file:///D:/CC/个人自媒体中枢/02-成果项目/商业报告解读/analysis/kazike-style-card.md) 改写为**有活人感的看盘短评**。
- **体量目标**：正文（3 短段 + 3 条观察边界 + 1 句感悟）控制在 **400 字左右**（不要扩成 500+ 字报告体，也不要压成 300 字内无因果报数）。
- **语气要点**：站在看盘人视角切入，多短句与具体动词，可用轻微反常识与冷幽默带出节奏（例：「好消息是……坏消息是……」），避免连续抽象术语与次要板块流水账。
- **不可突破红线**：
  1. **事实与结论零失真**：所有数字、均线/强弱/内外围结论及观察边界严格忠于已确认复盘稿，不新增事实、不改义、不编造持仓或买卖动作；
  2. **不使用夸张情绪词**（禁「颠覆 / 崩了 / 重磅 / 震惊」等）；
  3. **个人感悟逐字保留原句**，不顺带改写；
  4. **保留排版约束**：纯文本无 markdown、段落与 `·` 条目之间留空行、`$代码$` 三原则（≤3 个、不含上证指数）、38 字精简免责声明。

## 关键约束：雪球长文编辑器不支持 markdown（2026-09-24 立）

官方社区有用户明确反馈「复制、粘贴 markdown 格式的文本，表格的文本样式乱掉」，编辑器本身也不提供 markdown 输入模式。因此：

1. **正文一律出纯文本**——不使用 `**加粗**`、`![alt](path)`、行首 `-` 列表、`---` 分隔线。这些标记贴进雪球后不会被解析成富文本，只会原样显示或被吃掉，是「看着一坨、不分行」的主要来源。
2. **段落之间必须留空行**。单换行在粘贴过程中会被合并，空行才是可靠的段落边界。
3. **图片不能靠粘贴带上**。正文里只留一行占位提示，实际用编辑器工具栏手动上传。
3.5. **边界与观察的三条目之间也要空行**（2026-10-30 用户反馈）：短句列表的单换行同样会被合并，三条曾挤成一行；`bullets_to_plain` 现以空行拼接每个条目。
4. 加粗若要保留，由用户在雪球编辑器里用工具栏手动加，不由模板注入标记。

## 短评长度：三句主干（2026-09-24 改）

原先整段搬运博客摘要（360–570 字），用户反馈「下面的文字太多」。现改为脚本自动从摘要里**逐字截取三句主干**：

| 顺位 | 取哪句 | 关键词 |
|---|---|---|
| 1 | 首句（通常是量价） | — 固定取首句 |
| 2 | 结构 / 大小盘 | 结构、大小盘、小盘、大盘、两头、指数强于、降波 |
| 3 | 外围 | 外围、恒指、纳指、标普、道指、港股、美股、隔夜 |

命中不足时按原文顺序补足；最后按**原文出现顺序**排列。**只用原文句子，不新增、不改写、不拼接。** 改规则只改 `distribute.py` 顶部的 `DIGEST_*` 常量。

## 开头 #雪球星计划# 与「发布操作 · 曝光技巧」清单（2026-10-26 增补）

来源：雪球创作者中心《发帖技巧》（xueqiu.com/1130856323/195590323），用户要求固化进分发流程。五条技巧与落法：

| 官方技巧 | 落法 |
|---|---|
| 1. 关联股票，内容出现在所关联股票的讨论页 | **正文挂钩点自动生成 $代码$，三原则（2026-10-28 定版，雪球单篇最多 3 个代码关联）**：`distribute.py` 的 `make_ticker_linker` 对短评/边界里的宽基指数名（沪深300/创业板指/恒生指数含常用简称）就地转换，且 ① 重复代码只挂第一处；② 上证指数不挂；③ 全篇最多 3 个、第 4 个起保持纯文本。这是「短评逐字」规则的**唯一许可替换**；`上证50`、恒生科技、美股未获授权不转。**不关联个股**——与「无持仓、不构成投资建议」红线一致，避免荐股暗示 |
| 2. 关联话题，在该 #话题# 下展示 | 正文首行 `#雪球星计划#` + 文末标签行（#A股复盘# 等）发布后自动成为话题关联；清单里加一项确认渲染为蓝色话题链接 |
| 3. 文章开头添加 #雪球星计划# 话题 | `distribute.py` 正文**海报占位行之后、题眼之前**固定注入一行 `#雪球星计划#`（常量 `STAR_PLAN_TAG`）。它属**平台话题元数据、不属行情内容**，不受「短评逐字取自确认原文」约束 |
| 4. @今日话题 官号自荐 | 清单项：**发布后在评论区 @今日话题**（不自动注入正文，避免加长帖子——与 0924「正文太多」的反馈方向一致），编辑团队收到提示后优质原创可推荐至「今日话题」栏目 |
| 5. 主页置顶 | 清单项（可选）：希望访客第一时间看到的篇目（如当周周报复盘）用「主页置顶」 |

实现位置：`skills/distribute/scripts/distribute.py` 的 `STAR_PLAN_TAG` / `PUBLISH_OPS` 常量；2026-10-26 之前已生成、尚未发布的存量草稿（2026-10-26 日报、2026-W43 周报）已手工补齐同两项。
