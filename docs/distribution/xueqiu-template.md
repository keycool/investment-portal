# 雪球发布版 · 分发模板（xueqiu）

> 本模板为**固定框架**，`{{KEY}}` 占位符由 `skills/distribute/scripts/distribute.py` 从博客 MDX 派生。
> **雪球 = 主图海报（1080×2000）+ 突出重点短评**，不做完整长文（完整长文在个人博客）。
> 短评 = 题眼 + 三句主干 + 边界观察，**逐字取自母版，不新增不改义**。
> 发布时上传 `{{POSTER_FILE}}`；CTA 只引导到个人博客（`channels.ts` 的 `blogUrl`）。

---

## 关键约束：雪球长文编辑器不支持 markdown（2026-09-24 立）

官方社区有用户明确反馈「复制、粘贴 markdown 格式的文本，表格的文本样式乱掉」，编辑器本身也不提供 markdown 输入模式。因此：

1. **正文一律出纯文本**——不使用 `**加粗**`、`![alt](path)`、行首 `-` 列表、`---` 分隔线。这些标记贴进雪球后不会被解析成富文本，只会原样显示或被吃掉，是「看着一坨、不分行」的主要来源。
2. **段落之间必须留空行**。单换行在粘贴过程中会被合并，空行才是可靠的段落边界。
3. **图片不能靠粘贴带上**。正文里只留一行占位提示，实际用编辑器工具栏手动上传。
4. 加粗若要保留，由用户在雪球编辑器里用工具栏手动加，不由模板注入标记。

---

## 短评长度：三句主干（2026-09-24 改）

原先整段搬运博客摘要（360–570 字），用户反馈「下面的文字太多」。现改为脚本自动从摘要里**逐字截取三句主干**：

| 顺位 | 取哪句 | 关键词 |
|---|---|---|
| 1 | 首句（通常是量价） | — 固定取首句 |
| 2 | 结构 / 大小盘 | 结构、大小盘、小盘、大盘、两头、指数强于、降波 |
| 3 | 外围 | 外围、恒指、纳指、标普、道指、港股、美股、隔夜 |

命中不足时按原文顺序补足；最后按**原文出现顺序**排列。**只用原文句子，不新增、不改写、不拼接。** 改规则只改 `distribute.py` 顶部的 `DIGEST_*` 常量。

## 底部固定模块：2026-09-24 合并

原模板底部并排两段，内容重复：

| 原第 1 段（`aboutText`） | 原第 2 段（`BLOG_INTRO`） |
|---|---|
| 一个持续记录市场、公开判断边界并回看错误的交易学习者。**完整复盘、历史归档与后续校准**见博客「心猿意马的羊｜交易复盘」。 | 我的博客 · 心猿意马的羊｜交易复盘：**A 股每日复盘、历史归档与判断校准**的唯一入口 |

「完整复盘 / 历史归档 / 判断校准」在两段里各出现一次——纯粹重复。用户拍板**合并为「身份一句 + 博客地址」**：

```text
关于我：一个持续记录市场、公开判断边界并回看错误的交易学习者。完整复盘见博客：
https://www.fupanxinyuan.com
```

落法：

- `src/data/channels.ts` 的 `aboutText` **只留身份一句**，删掉句尾「完整复盘、历史归档与后续校准见博客『…』。」（该文件的注释里写明了为什么）。
- `distribute.py` 删去 `BLOG_INTRO` 常量，新增 `BLOG_BRIDGE = "完整复盘见博客："` 桥接语，正文拼成 `关于我：{ABOUT}{BLOG_BRIDGE}` + 换行 + `{BLOG_URL}`。
- 效果（0922 真实数据）：整块粘贴区 761 → **520 字**（−32%）。
- 删掉的是**重复表述**，不是信息：博客地址、完整复盘入口都还在，只是不再说两遍。若哪天要恢复「A 股每日复盘 / 唯一入口」这类搜索词，改 `BLOG_BRIDGE` 一处即可。

## 发布核对清单（固定项）

- [ ] 标题、题眼、短评、边界与已确认终稿一致（不新增、不改义）
- [ ] 短评只含母版原文句子（脚本自动截取三句主干，未改写）
- [ ] 已上传 `{{POSTER_FILE}}`（1080×2000 复盘海报），并已删掉正文里的「此处插入海报」占位行
- [ ] 正文里无残留 markdown 标记（`**` / `![` / 行首 `-` / `---`）
- [ ] 数据来源标注为「公开市场数据」，未补造具体行情提供方
- [ ] 无持仓、仓位、账户金额、收益截图或具体买卖动作
- [ ] 免责声明全文与 `docs/content/site-copy.md` 第 7 节一致
- [ ] 博客入口链接无误（站点已上线：{{BLOG_URL}}）
- [ ] 发布到雪球「文章」而非「讨论」
