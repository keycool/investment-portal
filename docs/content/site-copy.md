# 站点固定文案与条款

状态：2026-08-25 首页定稿版
适用范围：全站公共文案、页脚条款、公开边界与固定免责声明

本文档是全站固定文案与条款的**单一来源**。任何组件、页面或文章中的对应文字若与此处不一致，以本文档为准并应修正代码。修改文案必须先改本文档，再同步代码。

## 1. 品牌与站名

- 站名：`心猿意马的羊｜交易复盘`
- 品牌标识：header 左侧「羊」字标 + 站名（主行）＋「交易复盘」（副行）。
- 浏览器标题模板：首页为 `心猿意马的羊｜交易复盘`；其余页面为 `<页面名>｜心猿意马的羊`。
- 站点描述（meta description）：`持续记录市场事实、当前判断、判断边界与后续校准。`
- 页脚署名：`心猿意马的羊｜交易复盘`，副句：`记录市场，校准判断，与交易爱好者平视交流。`

## 2. 顶层导航

固定五项，顺序不可调整：

`首页 / 每日复盘 / 每周复盘 / 归档 / 关于`

- 桌面端一行显示；移动端两行显示署名与全部五项，不横向滚动。
- 当前页链接高亮，使用 `aria-current="page"`。

## 3. 首页 hero（首屏）

hero 区**只放文案，不放任何按钮、提示条或免责标签**：

- kicker：`MARKET REVIEW · OBSERVE / JUDGE / CALIBRATE`
- 大标题：`把每天的判断，留给时间检验。`（"留给时间检验。"为斜体强调）
- 副标题：`复盘是交易者的日课，它不只是为了交易做准备。它就是一份工作、一份记录。`

禁止出现：阅读按钮、浏览归档按钮、"不展示持仓"提示条、"不是投资建议"提示条、"封闭预览"标签。

## 4. 首页全部复盘列表

- 区块 eyebrow：`ALL REVIEWS`；标题：`全部复盘`。
- 说明：`按时间倒序，日复盘与周复盘统一列表。先看发生了什么，再看我如何理解，以及什么条件会推翻当前判断。`
- 日复盘与周复盘**不分块、不设"最新/最近"分区**，按 `date` 倒序混合排列为单一列表。
- 列表为空时显示 `暂无复盘`。

## 5. 首页研究工具

- eyebrow：`RESEARCH TOOLS`；标题：`研究工具`。
- 说明：`复盘之外的三项独立研究入口。它们提供观察证据，不自动生成本站判断，也不构成买卖建议。`
- 条目从 `src/data/researchTools.ts` 渲染，每项含序号、名称、说明与 `打开工具 ↗`，新窗口打开。
- 研究工具只以外部链接接入，不复制生产数据、不自动改写复盘判断。

## 6. 首页复盘原则

- eyebrow：`HOW I WRITE`；标题：`复盘不是答案，是可追踪的判断链。`
- 四项固定：
  - `01 事实`：记录可核验的数据、日期与来源。
  - `02 判断`：解释当前主要矛盾，不把观点伪装成事实。
  - `03 边界`：提前写下需要继续观察、可能推翻判断的条件。
  - `04 校准`：保留原文，以追加记录面对结果和偏差。

## 7. 固定免责声明（唯一文本）

首页最底部 `#disclaimer` 区块展示，全文一字不改：

> 本站内容仅为个人市场复盘、投资交易学习和研究记录，不构成投资建议、收益承诺、代客理财或具体买卖指令。市场有风险，任何决策都应基于独立判断并由决策者自行承担结果。

规则：

- 免责声明**不设独立页面**，只放在首页最底部，锚点 `/#disclaimer`。
- 全站页脚、文章来源区引用免责声明时，指向 `/#disclaimer`，不得引用 `/about/#disclaimer`。
- 文章页正文末尾的来源与免责声明区可展开同一文本，但不得改写措辞。
- `about` 页不再承载免责声明区块。

## 8. 页脚

- 左：站名 + 副句（见第 1 节）。
- 右链接固定三项：
  - `研究笔记` → `/research/`
  - `研究工具` → `/about/#tools`
  - `免责声明` → `/#disclaimer`

## 9. 公开边界条款

任何页面与文章不得公开：

- 持仓、仓位、账户金额、收益截图。
- 具体买入、卖出、止盈或止损动作。
- 个性化投资建议、代客操作或收益承诺。
- 未确认的题眼、点评或感悟。

原文判断不可重写；后续结果只以带日期的校准记录追加（见 `editorial-spec.md` 第 7 节）。
