# 人工发布与校准工作流

状态：2026-08-23 Astro 实现版

## 1. 权威链路

```text
飞书原始记录
→ 只读事实分析
→ 判断 / 点评 / 感悟逐段讨论
→ 三段全部人工确认
→ 一次性回填飞书并复核
→ 生成与核验海报
→ 手工编辑网站 MDX
→ 元数据、来源、海报和移动端预览
→ 本地或封闭预览
→ 后续事实出现
→ 按日期追加校准
```

飞书确认终稿是母稿。网站是公开编辑版，海报是结论摘要。三者发生冲突时暂停发布，对照飞书确认版本重新编辑。

## 2. 当日流程

### A. 发现与读取

1. 按编辑时间找到正确日期的飞书复盘，不凭浏览器当前页面猜测。
2. 分开识别市场事实、作者原判断、模板提示、图片和缺失内容。
3. 记录内容日期、主要数据截止日和所有数据来源。

### B. 分析与确认

1. 提炼“现象 → 结构 → 判断 → 条件”。
2. 依次形成今日/本周判断、收盘/周度点评和个人感悟。
3. 只有三段都得到明确确认，才能一次性回填。
4. 回填前重新读取 block ID；回填后验证三段内容和原始记录均未被破坏。

### C. 海报

1. 只使用已确认三段和可核验数字。
2. 日海报目标画布为 1080×2000。
3. 检查中文字体、换行、数字、单位、颜色含义、感悟和免责声明。
4. 标记为预览的海报不得冒充确认终稿。

### D. 网站公开编辑版

1. 新建 MDX `draft`，填写稳定 ID、日期、数据截止和来源。
2. 精简重复事实，但不改变原判断的方向、强度和边界。
3. 按“事实 → 结构 → 判断 → 边界 → 点评 → 感悟”排列。
4. 对照飞书确认终稿；核对后才升级为 `confirmed`。
5. 迁移并检查海报，补齐具体来源和真实完成时间。
6. 如有独立封面，检查替代文本、来源和使用权；没有封面时确认自动排版卡片正常。
7. 在本地检查文章、列表封面、归档、上一篇/下一篇和 390px 阅读。
8. 全部通过后升级为 `preview`。

## 3. 时间与完成记录

- 日复盘目标：A 股交易日当日 23:59 前进入网站预览。
- 周复盘目标：周日 23:59 前进入网站预览。
- `completed_at` 记录真正进入网站预览的时间，不记录计划时间。
- 未按时完成时保留空值或真实晚点时间，并在完成日志记录原因。
- 建设期网站未完成时，先保留确认终稿；内容集合可用后补录，但不能伪造原完成时间。

完成记录统一写入同目录的[内容完成时间记录](./completion-log.md)。

## 4. Preview 门槛

- [ ] 判断、点评和感悟均已确认。
- [ ] 事实、判断和边界可被读者清楚区分。
- [ ] `data_as_of`、具体来源、单位和比较基准完整。（行情数据按既有口径标注为「公开市场数据」，见 §6 来源口径例外）
- [ ] 2—3 天旧数据已说明，超过 3 天数据已标记待更新且未进入核心判断。
- [ ] 不含持仓、仓位、金额、具体买卖动作或个性化建议。
- [ ] 海报存在并通过尺寸、字体、溢出、颜色和底部检查。
- [ ] 独立封面来源合规且替代文本完整，或自动排版卡片显示正常。
- [ ] 免责声明完整。
- [ ] 原判断没有被后来结果重写。
- [ ] 稳定 URL、上一篇/下一篇和移动端预览正常。

## 5. 校准流程

1. 到原边界约定的验证窗口后重新读取原文章，不修改原正文。
2. 核对当时条件实际怎样变化，选择 `supported`、`partial` 或 `falsified`。
3. 追加校准日期、结果说明、偏差原因、错误标签和规则调整。
4. 更新 `updated_at` 和最近更新时间线；保留首次发布时间。
5. 校准内容再次经过人工确认后才进入预览或公开站点。

## 6. 失败与降级

- 找不到飞书确认终稿：保留 `draft`，不得依据海报反推完整母稿。
- 只有引流预览：只能登记为候选，不用于确认文章。
- 数据来源不具体：保留事实和缺口说明，不能升级为 `preview`。

## 6.1 来源口径例外（2026-09-10 定稿）

行情数据（成交额、涨跌家数、指数与板块涨跌、商品与外围报价）统一标注为**「公开市场数据」**，`url: null`，**不署名具体提供方、不补造提供方名称**。

此口径视为「来源完整」，**不构成本文 §6「数据来源不具体」的降级理由**，也不阻塞 `preview` 升级。理由：具体提供方（行情终端／数据商）与署名授权尚未确定，补造一个名称比留白更危险；读者需要的是数据日期与比较基准可核验，而非第三方背书。

`sources[].note` 写清数据性质与日期即可，例如：

```yaml
  - label: 公开市场数据
    url: null
    data_as_of: "2026-09-10"
    note: 行情数据取自公开市场行情，按既有口径不署名具体提供方（2026-09-10 定稿）。
```

飞书母稿来源仍须逐项署名并带 revision（见 `daily-review-notebook-poster/references/handoff-contract.md`）。
- 海报 PNG 缺失：正文可继续编辑，`poster.qa_status` 保持缺失或待迁移。
- 时间不足：先减少渠道改写和视觉变化，不削减复盘、来源检查和人工确认。
- 自动化失败：回到人工链路，不允许跳过确认或覆盖判断。

## 7. 永久禁止

不执行下单，不读取持仓后给动作，不修改交易策略或生产数据，不自动发布主观判断，不把网站内容反向写入飞书，不将研究指标包装成买卖信号。
