# 复盘交接收件箱

这是另一复盘工作台向投资博客项目提交已确认内容的唯一写入区域。

提交前必须完整读取：

```text
D:\CC\shared\investment-portal\skills\daily-review-notebook-poster\SKILL.md
D:\CC\shared\investment-portal\skills\daily-review-notebook-poster\references\handoff-contract.md
```

每次只新增一个目录：

```text
YYYY-MM-DD-daily/
├─ handoff.md
├─ poster-YYYYMMDD.html
├─ poster-YYYYMMDD.png
├─ notebook-background.png
└─ cover-YYYYMMDD.webp        # 可选

YYYY-Www-weekly/
├─ handoff.md
├─ poster-YYYYwWW.html
├─ poster-YYYYwWW.png
└─ cover-YYYYwWW.webp         # 可选
```

交接状态只有在判断、点评和感悟全部确认、飞书已一次性回填并复核、正式海报与 QA 均完成后，才能写为 `ready`。

独立封面不是 `ready` 的硬门槛。提供封面时必须同时填写替代文本、素材来源和使用权；封面缺失或不合规时，网站使用自动排版卡片，不影响正文接收。

不要在此目录放飞书原始全文、账户截图、持仓、仓位、具体买卖动作、临时截图或未注明状态的预览稿。不要修改本项目其他目录。
