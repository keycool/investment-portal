## 权威来源

权威顺序固定为：确认母稿 → 结构化输入 JSON → HTML → PNG → 网站公开编辑版。

- 不能从旧 PNG 反推完整文章。
- 缺失来源、日期或数值保持缺失，不得猜测。
- 工具名称可以变化，但“读取 → 人工确认 → 一次性写入 → 重新读取复核”的语义不能变化。
- 估值数据（周复盘或含「估值」栏的母稿）：数值只来自 `docs/operations/valuation-data.md` 定义的数据源——本地 `D:\CC\pe\data\` JSON（宽基 PE / 国债 / 波动率 / 换手集中度 / 红利股息率）与线上 ERP `https://index-compare-analysis.vercel.app/data/merged_signal.json`。只填事实数字并带数据日期，不生成“偏贵 / 便宜”判断；断档保持缺失不猜测。

## 确认门槛

正式海报必须同时满足：

1. 今日判断已确认；题眼采用“已发生事实 / 当前判断”，包含依据和保留边界。
2. 收盘点评已确认；涵盖量价与盘面、结构与风格、趋势边界、外围映射和后续观察。
3. 个人感悟已确认；一句、有作者态度、不重复点评、不写交易指令。
4. 三段已一次性回填母稿并重新读取核验。

未满足时只能生成 `preview`，不得写 `ready` 或虚构回填状态。

## 内容映射

结构化输入必须包含：

- `date`：ISO 日期。
- `display_date`：海报显示日期。
- `issue`：通常为 `MMDD`。
- `title`：两段式题眼（简洁、偏事实、不偏观点），第二段暗红强调。
- `lead`：核心事实、主要矛盾和边界，控制在两行半内。
- `facts`：两条最重要事实。
- `metrics`：恰好四组，每组含 `value`、`label`、`meaning`、`direction`。
- `columns`：恰好三栏，每栏三至五项；每项含 `label`、`value`、`direction`。
- `judgments`：恰好四项，依次覆盖量价、结构、风格/避险、外围。
- `watches`：恰好三项可验证条件。
- `summary`：一段，不超过三行。
- `quote`：一句个人感悟；可用换行控制两行节奏。
- `source_text` 与 `disclaimer`。

`direction` 只允许：

- `red`：明确走强或重要警示；
- `green`：明确走弱或下跌；
- `neutral`：无方向或仅作事实。

压缩顺序：删除重复数字 → 缩短列表 → 缩短句子 → 减少间距 → 微调行高 → 最后才小幅缩小字号。保留“事实 → 解释 → 判断 → 条件”。

## 视觉规范

- 背景：暖色木桌、暖白线圈本、左上绿植、右上书本；正文纸面保持干净。
- 字体：楷体/仿宋优先，近黑正文、暗红强调、深绿弱势数字。
- 版面：四个编号区块、四指标等宽、三栏结构、四项判断、三项验证、总结、感悟和页脚。
- 钢笔：仅一支、无笔帽、露尖、深炭黑哑光、少量低饱和暗金环与暗金花纹、无 Logo。
- 安全区：钢笔必须在右下角退出画面；不得碰总结红框，不得遮正文、感悟和页脚；与总结框之间必须存在可见留白。

需要编辑底图时使用任意模型可理解的精准局部编辑语义：

```text
只调整右下角钢笔及其即时阴影。把钢笔向右下移动并让更多笔身退出画面，使其不接触总结边框、正文、感悟和页脚。保持钢笔设计、比例、角度，以及纸张、线圈、木桌、绿植、书本、光线、颜色和裁切不变。不要增加笔帽、第二支笔、文字、Logo、墨迹或其他物体。
```

## 可复用经验

- 一开始就声明内容安全区，尤其是总结框和页脚；不要等完整排版后才判断装饰位置。
- 底图与正文分层：底图只承载环境和钢笔，所有文字保留在 HTML。
- 每次只改一个视觉变量；局部修改不能重生成整套内容。
- 是否遮挡必须查看完整合成 PNG；空白底图位置正确不代表正文合成后安全。
- 候选阶段使用版本号防止误覆盖；用户确认后清除被拒绝版本，避免旧逻辑再次被选中。
- 模板、输入结构和渲染脚本放在 Skill 内，避免依赖某台机器的历史目录。

## 验收清单

内容：

- 日期、正负号、单位、比较基准和来源正确。
- 题眼、总结和感悟与确认母稿一致。
- 外围变化说明了对 A 股的映射。
- 估值栏（如含）：数字来自权威数据源、带数据日期、无“偏贵 / 便宜”趋势判断。
- 免责声明完整。

视觉：

- PNG 为 `1080×2000`。
- 中文无乱码，标题、数字和列表无重叠。
- 内容没有越出纸面或被底部裁切。
- 钢笔与总结框有留白，且不遮感悟和页脚。
- 背景无拉伸、破图、重复或明显接缝。

文件：

- HTML、PNG 和背景属于同一版本。
- HTML 背景路径存在。
- 临时截图与被拒绝版本已清理。
