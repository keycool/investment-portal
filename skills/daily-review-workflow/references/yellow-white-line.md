# 黄白线（领先指数与综合指数）口径与跟踪规范

来源：用户 2026-11-10 口述普及（黄白线基础 + 三条衍生推论 + 深成指/创业板指样本 + 数据跟踪建议），2026-11-11 定版入册。本文是该指标的**唯一权威口径**；workflow SKILL 第 1 步的采集动作与判读落位以本文为准。

## 一、定义与数学含义

- **白线**：上证指数在时点上的指数价格，即**综合指数，含权、市值加权**——市值越大的股票对白线影响越大。深成指、创业板指各有自己的白线（各自的综合指数）。
- **黄线**：**领先指标（领先指数），不含权、等权**——每只股票权重相同，数学上可视为「贴近该市场的平均股价」。常被理解为「小盘股的线」，**从数学依据上讲确实如此**。
- **劈叉** = 黄线 − 白线（点数或 %）＝ 不加权平均涨幅 − 加权指数涨幅 ＝ **小票相对权重的超额表现**。

## 二、三条衍生推论（定版）

1. **推论一（赚钱效应）**：黄线强 ＝ 不加权平均好于加权指数 ＝ 多数个股表现好于综合指数 ＝ 人气与赚钱效应好。
   实例（2026-11-10）：黄线 3713.99 / 白线 3663.72，差 50.27 点 ≈ 1.37%；当日上海市场涨 1600 余家、跌 600 余家。
2. **推论二（日内修复）**：劈叉比较大时，盘中日内通常有一个「劈叉 → 收敛修复」的过程。与 **沪深300ETF/中证500ETF 比价、中证1000ETF/沪深300ETF 比价**（乃至 2000ETF/沪深300ETF 比价）密切相关，相关性**主要体现在日内**。
   → 每日统计两个量：**日内最大离散多远** + **收盘最终有没有归拢收敛**，连续积累后再据其得出结论。
3. **推论三（结构性矛盾）**：劈叉越大 ＝ 大盘与小盘越不同步，**常出现在成交金额偏小的阶段**。
   → 研究方向：**成交金额大小 × 黄白线劈叉幅度** 的关系。
   实例（2026-11-10→11-11）：劈叉 1.37% 时两市成交 1.48/1.50 万亿（低位）；11-11 放量 1.68 万亿 → 劈叉收敛到约 0.5——两个变量同日验证。

## 三、深成指与创业板指的黄白线

- **深成指**（2026-11-10）：综合 11241 / 领先 11368，差约 120 点（>1%）。
- **创业板指**（2026-11-10，日内劈叉翻转的极端样本）：开盘白上黄下约 1% → 收盘黄上白下约 1%，**里外里差了 2%**。

## 五、每日跟踪规范（2026-11-11 起执行）
