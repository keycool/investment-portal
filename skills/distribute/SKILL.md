# 内容分发（distribute）

从**博客 MDX 母版**单向降级派生分发草稿：
- **雪球** = 主图海报(1080×2000) + 题眼/摘要/边界短评（完整长文在博客）—— **主打引流战场（active）**
- **小红书** = 引流版海报(1080×1440) + 一句话钩子 —— **暂停（paused，2026-08-31 起，默认不产出；恢复时加 `--with-xhs`）**

制作中心在博客，分发物从母版派生，不重复造。

## 必读资源

1. 分发模板：`docs/distribution/xueqiu-template.md`（`xhs-template.md` 已暂停，保留供将来启用）。
2. 渠道配置：`src/data/channels.ts`（渠道定位、status、CTA、标签、博客链接、免责声明唯一文本）。
3. 生成规则总纲：`docs/operations/poster-production-rules.md`（确认门槛、题眼措辞、QA、CTA 合规）。

## 标准流程

1. **确认母版就绪**：博客 MDX 已完成（7 段正文 + `**确认原文**` 标记 + frontmatter），且三段已确认。
2. **运行派生脚本**：

   ```text
   python skills/distribute/scripts/distribute.py <mdx路径> --out content-inbox/<日期>-daily/
   ```

   默认只生成 `xueqiu-publish-draft-YYYYMMDD.md`（小红书暂停）。将来恢复小红书时加 `--with-xhs`。
   周稿（`type: weekly`）由脚本按 frontmatter 自动用周稿口径：标题「周度复盘」、海报文件名取 `poster.src`、来源 `content-inbox/<id>/handoff.md`、标签 `#周度复盘`——2026-09-08 起无需手工修正；早期旧版本产物需人工核对上述字段。
   **雪球正文是纯文本粘贴版、不是 markdown**（2026-09-24 改）：雪球长文编辑器不支持 markdown，故正文已去掉 `**`、`![ ]( )`、行首 `-`、`---`，段落之间留空行；短评由脚本从摘要里**逐字截取三句主干**（量价 + 结构/大小盘 + 外围），不再整段搬运。细则见 `../../docs/distribution/xueqiu-template.md`。
3. **人工补缺**：脚本只自动填充可派生的字段——关键事实表「说明」列需人工补。
4. **核对清单过目**：草稿文末带发布核对清单，逐项过一遍才可发。
5. **状态登记**：发布后更新 `docs/operations/distribution-log.md`（append-only）。

## 雪球发布操作技巧（2026-10-26 增补，来自雪球创作者中心）

官方《发帖技巧》五条已固化进派生物与核对清单，细则见 `docs/distribution/xueqiu-template.md` 对应节：

1. **正文开头注入 `#雪球星计划#`**（`distribute.py` 常量 `STAR_PLAN_TAG`，落在海报占位行之后、题眼之前）——便于官方运营发现优质原创并推荐。它是**平台话题元数据、不属行情内容**，不受「短评逐字」约束。
2. **「发布操作 · 曝光技巧」清单节**（`PUBLISH_OPS` 常量，草稿末尾）：关联股票 / 关联话题 / @今日话题 / 主页置顶 四个**发布时编辑器操作**，不注入正文。
3. **关联股票：正文挂钩点自动生成 $代码$，三原则（2026-10-28 用户定版）**——`distribute.py` 的 `make_ticker_linker` 对短评/边界里的宽基指数名（沪深300/创业板指含「创业板」/恒生指数含「恒指」）就地转换，且：**① 重复代码只挂第一处；② 上证指数不挂；③ 全篇最多 3 个代码（雪球单篇上限），第 4 个起保持纯文本**。链接器状态跨短评与边界共享。这是「短评逐字取自确认原文」规则的**唯一许可替换**；`上证50`、恒生科技、美股三大指数未获授权不转，要扩清单先问用户。只关联宽基指数、不关联个股——与「无持仓、不构成投资建议」红线一致，避免荐股暗示。
4. **@今日话题 自荐走评论区**，不自动写进正文（避免加长帖子——0924 用户反馈「正文太多」）。
5. 存量已生成但未发布的草稿需手工补齐这两处（2026-10-26 已补：10-26 日报、W43 周报）；已发布的历史草稿不回改。

## 不可变规则

- 判断 / 点评 / 感悟必须逐字取自博客 `**确认原文**`，不新增、不改义。
- **雪球正文出纯文本，不出 markdown**（2026-09-24 立）：雪球长文编辑器不支持 markdown，`**` / `![ ]( )` / 行首 `-` / `---` 贴进去不会被解析，只显示成标记或被吃掉，是「不分行、看着一坨」的主因。段落边界**只靠空行**，不靠单换行。雪球短评 = 从摘要**逐字截取**三句主干（量价 + 结构/大小盘 + 外围），不新增不改写、不整段搬运。
- **短评取句的关键词表只能放「品名词」（2026-09-24 踩坑）**：`distribute.py` 的 `DIGEST_KW_STRUCT` 现为 `("大小盘", "小盘", "大盘", "微盘", "小票", "两头", "降波")`。两条禁令——① **不得放结论短语**（如「指数强于」，会命中「领先指数强于上证」抢走顺位）；② **不得放裸词「结构」**（会命中「短期**均线结构**转弱」）。首轮出稿曾因此把短评排成「量价 + 外围 + 主要矛盾」，换成纯品名词后回归正确三句。要更短可调 `DIGEST_MAX_SENTENCES`。
- 雪球配 1080×2000 复盘海报；正文禁持仓/仓位/账户金额/收益截图/具体买卖动作。
- 免责声明只用 `site-copy.md` §7 唯一文本；CTA 只引导到个人博客（`channels.ts` 的 `blogUrl`）。要压免责声明必须先改 site-copy 再同步 `channels.ts`，不得单侧缩短。
- 小红书渠道暂停期间不生成、不发布小红书草稿（恢复条件见 `channels.ts` 中 xhs.status）。
- 不运行或修改 ERP、PE、相对比价策略及交易执行。

## 失败汇报

真正卡住时报告：输入 MDX 路径、当前阶段、完整错误、已生成/缺失字段、未执行的越界动作。
